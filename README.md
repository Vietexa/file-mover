# file-mover
### Automatically move files from the Downloads directory to other directories on Linux 

This application allows you to move files that are inside your Downloads directory to other directories such as Documents, Movies, Videos etc. 
This is process is done automatically just by running the application.

### Building Process
On Linux Distributions do the following:

```mkdir build```

```./build.sh```

after that the executable should be in your ``build`` folder
